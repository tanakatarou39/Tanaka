# ひとしずくの旅 — The Journey of a Single Drop of Light

約3分（3:00）の、途切れのない一続きのアニメーション。HTML + Canvas だけで動き、画像も音声ファイルも使いません（映像も BGM もコードから生成）。

一滴の光が、深い海で目をさまし、水面を越えて空へのぼり、雲になって雨として落ち、大地の種に触れて木になり、四季をめぐって星になり、また海へ還る。最後は最初の「一点の光」に戻るので、ループしても物語がつながります。

| 時間 | 場面 |
|---|---|
| 0:00 | 目ざめ — 闇の中の一点の光、心拍とひろがる光輪 |
| 0:14 | 深海 — プランクトンの渦、クラゲ、巨大なクジラ |
| 0:44 | 夜明け — 水面の裏側、スローモーションで水面を越える、朝日の海 |
| 1:12 | 空と雲 — 雲を抜け、無数のしずくが集まって雲になる |
| 1:38 | 雨 — 雲の底が開き、虹と山と森をぬけて土の中へ |
| 2:02 | 芽ばえと季節 — 種が目をさまし、春夏秋冬のタイムラプス |
| 2:32 | 星 — 花びらが星になり、オーロラと「ひとしずく座」 |
| 2:46 | 還る — 星が海へ落ち、波紋、潜行、再び一点の光へ |

## 見る

- **MP4**: `dist/hitoshizuku.mp4`（1280×720、30fps、BGM入り、字幕入り）
- **ブラウザ**: `dist/hitoshizuku.html` をダブルクリック（単一ファイル。オフラインでも動きます。Web フォントだけはオンライン時に読み込み）
- 開発用: `index.html`（`src/` を読み込みます）

操作: クリック/スペース=再生・一時停止、← →=5秒移動、M=ミュート、F=全画面、下のバーでシーク。スマホの縦画面にも対応しています。

## しくみ

- すべての場面は **時刻 T の純粋関数**です（フレーム間の状態なし）。そのためシーク、ループ、フレーム単位の書き出しが正確にできます。
- 場面は 4 秒ずつ重なり、その間は **主人公（光のしずく）の位置・色と背景を両側で一致**させてクロスフェードします（`docs/DESIGN.md` §3 の「ハンドオフ契約」）。
- 描画は加算合成のグロー・低解像度のプロシージャル場・事前描画スプライト。端末の性能は起動時に測り、必要なら解像度を自動で下げます。
- 音楽は Web Audio による生成（ニ長調ペンタ系、心拍・クジラ・雨・鐘・合唱風パッド）。映像の時刻に厳密に同期します。

```
index.html            ページ（字幕・開始カード・操作バー）
src/core.js           ユーティリティ + エンジン（合成・ブルーム・ビネット・粒状感）
src/timeline.js       場面表・字幕（日本語/英語）・全体フェード
src/hero.js           主人公の見た目とハンドオフ表
src/scenes/s1..s8     8つの場面
src/audio.js          生成BGM
tools/                shot / check / pops / perf / build / video / audio_render
docs/DESIGN.md        物語・契約・各場面の設計
```

## 検証ツール（Node + Playwright/Chromium）

```
node tools/shot.mjs --times 0:180:3 --cols 4 --out sheet.png      コンタクトシート
node tools/shot.mjs --times 14:18:1 --triple s1_awakening,s2_deepsea --out b1.png   境界の A|B|重ね + 差分
node tools/check.mjs --step 4.5 [--size 390x844]                  決定性（同じTなら同じ絵）とエラー
node tools/pops.mjs                                               全編の急変（ポップ/ちらつき）検出
node tools/perf.mjs --nofx                                        フレームコスト
node tools/build.mjs                                              dist/ に単一HTMLを生成
node tools/video.mjs --audio film.wav --out dist/hitoshizuku.mp4  全編をフレーム単位で書き出し
```
